# M3 Task43 Soak Evidence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and execute a fail-closed M3-V7 soak harness that measures production persistence correctness, resource bounds and frozen performance thresholds, then binds its Formal PASS to same-commit Task41 and Task42 evidence.

**Architecture:** A test-only C++ executable exercises production storage/persistence paths and emits one versioned JSON summary per deterministic seed. A PowerShell orchestrator runs Quick or Formal profiles in fresh processes, saves raw logs, binds real-environment evidence and atomically publishes one report; `Verify-M3Json.ps1` independently validates every threshold and provenance field. `Invoke-M3Verification.ps1 -Tier Soak` is the only public route.

**Tech Stack:** C++20/MSVC, CMake/CTest, PowerShell 5.1, Win32 process/resource APIs, existing MYRD storage/persistence libraries, SHA-256 JSON evidence.
