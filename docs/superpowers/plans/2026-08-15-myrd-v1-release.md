# MyRamDisk v1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Qualify the existing M4 product inside the frozen Windows 11/AIM support profile and publish an integrity-verifiable `v1.0.0` CLI release without expanding product scope.

**Architecture:** First turn all release metadata and previously proven Formal VM support helpers into tested, versioned inputs, then freeze one release-candidate commit. Run one bounded Formal12 from a fresh VM root with exactly two hard-reset opportunities and eight realistic Negative cases; permit at most one defect-specific Formal13. Finish with the existing R8 local matrix, a docs-only release record, an exact ZIP manifest and tag.

**Tech Stack:** C++20, CMake 3.25+, Ninja Multi-Config, Visual Studio 2022 Build Tools x64, PowerShell 5.1, CTest, VMware Workstation `vmrun`, OpenSSH/SCP, Windows Storage cmdlets, Arsenal Image Mounter DirectAimAdapter.
